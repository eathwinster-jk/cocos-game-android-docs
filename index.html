下载

下载 Android AARgame-sdk-0.1.0.aar · arm64-v8a 下载测试 Demo APK支持账号密码或 UID Token 两种登录模式

compileSdk 35minSdk 26targetSdk 34JDK 17arm64-v8a

接入前准备

  • 宿主客户端完成用户登录并获得 liveUserId、liveToken。
  • 宿主动态传入 sceneType：1 直播间，2 IM 群。
  • 宿主动态传入 sceneId，SDK 不内置固定场景。
  • 正式环境必须使用 HTTPS/WSS。

模式一：本地 AAR 接入

1. 复制文件

app/libs/game-sdk-0.1.0.aar

2. Gradle Groovy

android {
    compileSdkVersion 35
    defaultConfig {
        minSdkVersion 26
        targetSdkVersion 34
        ndk { abiFilters "arm64-v8a" }
    }
    packagingOptions { jniLibs { useLegacyPackaging true } }
}
dependencies {
    implementation files("libs/game-sdk-0.1.0.aar")
}

3. Kotlin DSL

android {
    compileSdk = 35
    defaultConfig {
        minSdk = 26
        targetSdk = 34
        ndk { abiFilters += "arm64-v8a" }
    }
    packaging { jniLibs { useLegacyPackaging = true } }
}
dependencies {
    implementation(files("libs/game-sdk-0.1.0.aar"))
}

模式二：Gradle 远程接入（推荐）

1. settings.gradle.kts

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven {
            url = uri("https://raw.githubusercontent.com/eathwinster-jk/cocos-game-android-sdk/main/repository")
        }
    }
}

2. app/build.gradle.kts

dependencies {
    implementation("com.eath.cocosgamesdk:game-sdk:0.1.0")
}

请固定版本号，不使用 + 或 latest 动态依赖。

权限与混淆

AAR 已合并 INTERNET、ACCESS_NETWORK_STATE、VIBRATE 权限和游戏 Activity。

-keep class com.eath.cocosgamesdk.** { *; }
-keep class com.cocos.lib.** { *; }
-dontwarn com.cocos.lib.**

初始化 SDK

在主进程 Application 中只初始化一次，且早于其他 SDK 调用。

Java

public final class App extends Application {
    @Override public void onCreate() {
        super.onCreate();
        CocosGameSDK.getInstance().initialize(this);
    }
}

Kotlin

class App : Application() {
    override fun onCreate() {
        super.onCreate()
        CocosGameSDK.getInstance().initialize(this)
    }
}

创建会话并打开游戏

Java

GameSessionConfig session = new GameSessionConfig(
    websocketUrl,
    apiBaseUrl,
    liveUserId,
    liveToken,
    sceneType,
    sceneId,
    0,
    BuildConfig.VERSION_NAME,
    "Android"
);
CocosGameSDK.getInstance().openGame(this, "niuniu", session);

Kotlin

val session = GameSessionConfig(
    websocketUrl,
    apiBaseUrl,
    liveUserId,
    liveToken,
    sceneType,
    sceneId,
    0,
    BuildConfig.VERSION_NAME,
    "Android",
)
CocosGameSDK.getInstance().openGame(this, "niuniu", session)

UID、Token、Scene Type、Scene ID 必须由宿主客户端传入，不能固定写在 SDK 中。

会话失效与公共事件

会话失效

if (requestCode == CocosGameSDK.GAME_REQUEST_CODE
        && resultCode == Activity.RESULT_CANCELED
        && data != null
        && data.hasExtra(CocosGameActivity.EXTRA_SESSION_ERROR)) {
    clearLoginSession();
    openLoginPage();
}

Java 公共事件

CocosGameSDK.getInstance().setHostListener(
    (gameId, event, payloadJson) -> {
        if ("wallet.open".equals(event)) openWalletPage();
    }
);
CocosGameSDK.getInstance().sendGameEvent(
    "wallet.closed",
    "{\"isBalanceChanged\":true}"
);

Kotlin 公共事件

CocosGameSDK.getInstance().setHostListener { gameId, event, payloadJson ->
    if (event == "wallet.open") openWalletPage()
}
CocosGameSDK.getInstance().sendGameEvent(
    "wallet.closed",
    """{"isBalanceChanged":true}""",
)

运行测试 Demo

源码：cocos-game-android-demo

  1. 下载上方 Demo APK，安装到 API 26 以上的 ARM64 设备；或克隆源码构建。
  2. 输入 Scene Type：1 直播间，2 IM 群。
  3. 输入当前 Scene ID。
  4. 选择账号密码登录，或输入 Live User ID、Live Token。
  5. 点击对应按钮打开游戏。
adb install -r game-sdk-demo-0.1.0.apk

常见问题

Gradle 无法下载

确认可访问 raw.githubusercontent.com，然后执行 ./gradlew --refresh-dependencies。

x86 模拟器不能运行

当前 SDK 仅包含 arm64-v8a，请使用 ARM 模拟器或 ARM64 真机。

会话认证失败

确认 UID 与 Token 匹配、未过期，HTTP 与 WebSocket 属于同一环境。

找不到桌台

确认 Scene Type、Scene ID 以及后台开桌场景完全一致。
