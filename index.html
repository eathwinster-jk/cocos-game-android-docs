接入前准备

  • 宿主客户端完成用户登录并获得 liveUserId、imUserId、liveToken。
  • 宿主动态传入 sceneType：1 直播间，2 IM 群。
  • 宿主动态传入 sceneId，SDK 不内置固定场景。
  • 正式环境必须使用 HTTPS/WSS。

5 分钟快速接入

  1. 在 settings.gradle.kts 添加 GitHub Maven 仓库。
  2. 在 App 模块添加 game-sdk:0.1.7。
  3. 在主进程 Application 初始化 SDK。
  4. 客户端登录后创建 GameSessionConfig。
  5. 调用 openGame(activity, "niuniu", session)。
maven {
    url = uri("https://raw.githubusercontent.com/eathwinster-jk/cocos-game-android-sdk/main/repository")
}

implementation("com.eath.cocosgamesdk:game-sdk:0.1.7")
CocosGameSDK.getInstance().initialize(applicationContext)

val session = GameSessionConfig(
    websocketUrl, apiBaseUrl, liveUserId, imUserId, liveToken,
    sceneType, sceneId, 0, BuildConfig.VERSION_NAME, "Android"
)
CocosGameSDK.getInstance().openGame(activity, "niuniu", session)

SDK 不提供生产登录。UID、Token、Scene Type、Scene ID 必须由宿主客户端传入。

GameSessionConfig 参数

参数规则

apiBaseUrl必须为 https://
liveUserId客户端登录后的直播 UID（登录响应 uid），用于大厅鉴权，大于 0

deviceTypeAndroid

客户端与 SDK 职责

客户端负责

  • 账号登录、Token 刷新和退出。
  • UID、Token、Scene Type、Scene ID。
  • 游戏入口、权限和风控判断。
  • 会话失效后返回登录流程。
  • 决定是否执行横竖屏切换。
  • 自定义钱包、充值或其他业务页面。

SDK 负责

  • Cocos Activity 和游戏模块加载。
  • 大厅 HTTP、WebSocket、重连和快照恢复。
  • 游戏资源、音频和生命周期。
  • 入座、下注、结算与界面状态。
  • 容器尺寸回传和游戏等比适配。
  • 固定退出、下注与通用事件桥。

Demo 登录模式

账号密码

Demo 调用测试登录接口，将服务端返回的 UID、Token 注入 GameSessionConfig。账号密码不写入 SDK，也不持久化。

UID Token

直接输入已有 UID、Token。两种模式都需要客户端输入或确认 Scene Type、Scene ID。

账号密码登录仅用于 Demo。正式客户端必须复用自身登录体系。

生命周期、旋转与弹窗

  • 进入后台时 SDK 暂停音频和实时连接；回前台重新同步权威桌态。
  • 旋转按钮只向客户端发请求，是否旋转由客户端决定。
  • 客户端完成布局后回传实际游戏容器宽高，游戏只负责界面适配。
  • SDK 内置退出确认和下注卡；钱包、充值等业务页面通过公共事件接入。
  • 规则弹窗关闭、大屏切小屏后应继续验证全部按钮可点击。

我的记录接入

「我的记录」由 SDK 内置实现，客户端无需调用任何新 API、无需注册回调，升级到 v0.1.4 及以上即可使用。用户在游戏内点击「规则」按钮，切换到「我的记录」页签即可查看本人注单，页面以原生弹窗展示。

工作方式

  • SDK 使用 GameSessionConfig 中的 apiBaseUrl、liveUserId、liveToken 直接请求后台，请求头与入座、下注接口相同（live-user-id、live-user-token）。
  • 当前本桌：POST /api/lobby/bet/table/mine，按当前桌号查询，游标分页。
  • 历史场次：POST /api/lobby/bet/history，按下注日期区间查询，游标分页。
  • 每页 20 条，列表滑到底部自动加载下一页；加载失败显示点击重试，无数据显示空状态。
  • 顶部场景标签取自 sceneType、sceneId 和实际进入的桌号。

页面功能

页签功能
当前本桌本桌完成局数、本人赢/输、本人净输赢；全部 / 在座下注 / 观战跟注筛选
历史场次最近 30 天 / 最近 7 天 / 今天；桌号、局号搜索；按桌台和日期分组，净输赢为扣除抽成后金额；顶部展示区间完成局数、赢/输与净输赢

客户端需确认

  • apiBaseUrl 指向的大厅网关已开放上述两个接口，且与入座、下注使用同一环境。
  • liveToken 在游戏期间保持有效；Token 失效时记录页显示加载失败，点击可重试。
  • 记录只展示当前登录用户本人的注单，不涉及其他用户数据。

常见问题

Gradle 无法下载

确认可访问 raw.githubusercontent.com，然后执行 ./gradlew --refresh-dependencies。

x86 模拟器不能运行

当前 SDK 仅包含 arm64-v8a，请使用 ARM 模拟器或 ARM64 真机。

提示 sessionConfig 不能为空

SDK 不允许无会话启动。客户端必须先传入 UID、Token、Scene Type、Scene ID。

会话认证失败

确认 UID 与 Token 匹配、未过期，HTTP 与 WebSocket 属于同一环境。

我的记录加载失败或为空

确认大厅网关已开放 /api/lobby/bet/table/mine 与 /api/lobby/bet/history，Token 未过期；当前本桌需先成功进入桌台，历史场次可切换为最近 30 天查看。

找不到桌台

确认 Scene Type、Scene ID 以及后台开桌场景完全一致。

AAR 冲突或找不到 native 库

确认仅保留一个 SDK 版本、启用 arm64-v8a，并检查 APK 中存在 lib/arm64-v8a/libcocos.so。

  • Token 失效后能返回客户端登录流程。
